Add Global incidents, powered by Cloudflare. The first row of the Security Advisories section lists Cloudflare Radar briefings on large, widespread incidents from the last 30 days, such as runtime RCEs and compromised certificate authorities, which package advisories don't cover. Briefings that need attention are listed first with their recommended action, and new ones trigger a prioritized notification, which can be turned off in Settings → Advisories.
