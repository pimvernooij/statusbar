Add security advisory monitoring. Follow an ecosystem or specific packages (for example `npm: next, react`) and the dropdown lists high and critical advisories from the GitHub Advisory Database published in the last 7 days, with relative timestamps and links to GitHub. Each topic can follow high, critical or both. New advisories trigger Time Sensitive notifications. Topics, check interval and notifications are managed in a new Advisories settings tab.
